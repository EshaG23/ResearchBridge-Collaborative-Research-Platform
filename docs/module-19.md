# Module 19: completion and research outcomes

Mentors and leaders can request completion. The approved project mentor confirms completion or reopens research, with a note, explicit confirmation and revision checks. Completing research closes recruitment. Reopening research does not automatically reopen recruitment. Existing chat, tasks, evidence and history stay available to authorised members.

IP Progress now contains private, immutable mentor updates, required-information requests, task references and protected attachments. Only explicitly approved, separately entered achievement summaries appear on the shared dashboard for 365 days by default. Private IP text and files are never copied there. Mentors can withdraw a shared achievement while retaining its history.

Transactional events and notifications support safe retries. Tests cover permissions, stale actions, private-file access, duplicate actions, completion, reopening and achievement publication/withdrawal.
